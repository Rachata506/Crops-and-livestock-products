OUR WORKFLOW

Data processing notes

Expand each step to see how the dataset should be prepared before analysis and visualization.

01 Data selection

Select relevant countries, years, commodities and elements from the QCL dataset based on the objectives of the dashboard.

02 Data cleaning

Check column names and data types, identify duplicate records, and inspect missing or unavailable values. Missing values should not automatically be treated as zero.

03 Data preparation

Standardize country, year, item and element fields. Check measurement units and apply consistent filters before comparing or aggregating values.

04 Data visualization

Present the prepared data using suitable charts, tables and comparisons. Include clear titles, labels, units and source notes.

PLEASE NOTE

Data limitations

Data availability and reporting periods may differ between countries and commodities. Some records may be estimated, revised or missing. Comparisons should use consistent years, elements and units.

Always refer to the original FAOSTAT dataset and metadata when interpreting results.
